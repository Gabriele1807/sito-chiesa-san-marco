# UI/UX Redesign Notes (May 2, 2026)

## Sources and patterns applied
- Navbar.gallery: thin announcement strip, compact desktop nav with visible active state, sticky header with soft blur.
- Footer.design: multi-column grid, dark footer base with clear section headings, bottom legal strip.
- CTA.gallery: clear primary/secondary button hierarchy, consistent focus rings and hover lift.
- Supahero: split hero layout, large headline + supporting card, layered soft gradients and shapes.

## How the redesign maps to the site
- Hero (home): two-column composition with a large spiritual headline, short mission copy, two CTAs, and a next-celebration card for immediate context.
- Navbar + sidebar: announcement bar for key updates, stronger spacing and readable links, clearer active state for navigation.
- Footer: four-column layout (about, liturgy hours, contacts, quick links + social), high contrast but aligned to the liturgical palette.
- CTA system: shared button classes (primary, secondary, ghost, link) reused across cards and actions.

## Liturgical coherence
- All new styling uses existing CSS tokens (background, primary, accent, gold, sage) with no new hardcoded colors.
- Typography emphasizes a more ceremonial tone (display serif for headings, calm body face) while staying readable in both locales.
- Layout and spacing remain respectful and calm, avoiding a startup aesthetic.
